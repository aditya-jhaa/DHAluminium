Aluminium Windows

Aluminium Sliding Windows Melbourne

The most widely used window style in Australian homes. Sashes slide horizontally within the frame, so nothing projects into or out of the room — practical for walkways, decks and anywhere space is tight.

Sliding windows suit you if…

  • You want a simple, familiar window that's easy to operate
  • The window opens onto a path, deck or narrow side access
  • You're replacing existing sliders like for like
  • You want a cost-effective option across a whole house
  • You need wide openings without a projecting sash

Worth considering instead…

  • Awning windows, if you want to leave windows open in light rain
  • Double hung, if you're matching a period or traditional style
  • Sashless, if uninterrupted glass and easy cleaning matter most

Common Questions

Are sliding windows secure?
Modern sliding windows use keyed locks and interlocking sashes. For added security we can fit stainless steel security mesh screens, which are tested to resist knife shear and impact while still allowing airflow.
Can sliding windows be double glazed?
Yes. Double glazing improves both thermal comfort and noise reduction, and is available across our sliding window range with clear, Low-E or obscure glass depending on the room.
How long will it take?
Production is typically completed within three to four weeks of your order being confirmed. Installation is usually finished in a single day, scheduled around your availability.
Can I arrange my own installation?
Yes. We offer supply only as well as supply and installation, so you can use your own trades if you prefer. Builders regularly order supply only from us.
What colours are available?
Everything is finished in powder coat, with a wide standard colour range plus custom colours on request. Charcoal, black and monument are the most common choices we install.
Do you replace windows in an existing home?
Yes, replacement work is a large part of what we do. We measure your existing openings, fabricate to suit, and remove the old windows as part of the installation.
